## Apa itu Iterative Prompting
Iterative prompting adalah teknik memberi feedback secara bertahap sampai output
sesuai kebutuhan. Kamu tidak menulis prompt panjang sekali jadi, tapi
mengembangkan step demi step.

## Kapan Dipakai
- Task kompleks dengan banyak detail
- Butuh format yang rapi
- Ingin output yang presisi

## Contoh
**Prompt 1:**
```
Buat outline artikel tentang keamanan WiFi rumah.
```

**Prompt 2:**
```
Tambahkan bagian tentang tools yang aman untuk pemula.
```

**Kenapa berhasil:**
Iterasi menjaga arah konten tanpa membuat prompt terlalu panjang.
